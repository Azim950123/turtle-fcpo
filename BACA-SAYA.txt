TURTLE FCPO 30 HARI — CARA JADIKAN APP LIVE (GitHub Pages)

Isi folder ini:
  index.html            -> app
  manifest.webmanifest  -> maklumat app (nama, ikon, warna)
  sw.js                 -> membolehkan app dipasang & dibuka tanpa internet
  icons/                -> ikon app (5 fail)

LANGKAH 1 — Muat naik ke GitHub
  1. Log masuk github.com
  2. Klik "+" (kanan atas) -> New repository
  3. Repository name: turtle-fcpo   |   pilih Public   |   klik Create repository
  4. Klik pautan "uploading an existing file"
  5. Seret SEMUA isi folder ini (index.html, manifest.webmanifest, sw.js, folder icons, fail ini)
     ke kotak muat naik. Pastikan folder "icons" ikut dimuat naik.
  6. Klik Commit changes

LANGKAH 2 — Hidupkan GitHub Pages
  1. Dalam repo, klik Settings -> Pages (menu kiri)
  2. Source: Deploy from a branch
  3. Branch: main   |   folder: / (root)   |   klik Save
  4. Tunggu 1–3 minit, refresh. Pautan keluar di atas:
     https://NAMA-PENGGUNA-ANDA.github.io/turtle-fcpo/

LANGKAH 3 — Pasang (download) app
  Android (Chrome):  buka pautan -> menu ⋮ -> "Install app" / "Add to Home screen"
  iPhone (Safari):   buka pautan -> butang Share (kotak + anak panah) -> "Add to Home Screen"
  Laptop (Chrome/Edge): buka pautan -> ikon pasang di hujung kanan bar alamat -> Install

KEMAS KINI APP
  1. Ganti index.html di GitHub (Add file -> Upload files -> commit)
  2. Buka sw.js di GitHub -> ikon pensel -> tukar  turtle-fcpo-v1  kepada  turtle-fcpo-v2  -> commit
  3. Tutup & buka semula app (kadang-kadang 2 kali) untuk dapat versi baru

NOTA
  - Kemajuan (tanda Siap) disimpan dalam peranti masing-masing, bukan di GitHub.
  - Repo Public bermaksud sesiapa yang ada pautan boleh lihat app ini.
